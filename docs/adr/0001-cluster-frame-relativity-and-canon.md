# Use a shared Cluster Frame while preserving canon separately

Model Systems as stationary in one Centauri Cluster inertial frame, define Gate cruise speed as exactly 0.999c in that frame, and derive Ship Proper Time with special relativity. Preserve cited canonical durations independently and expose disagreements as Canon Discrepancies rather than changing physical inputs or silently correcting canon; this keeps journeys comparable while acknowledging that the fiction may not be internally SR-consistent.
